# Nislo Rudas — DJ & Producer

Sitio oficial / EPK de **Nislo Rudas**, DJ panameño (David, Chiriquí) de minimal & tech house.
Diseño inspirado en la estructura editorial de clovisdj.com.

## Stack

HTML5 + CSS3 + JavaScript vanilla — sin frameworks, sin build.

## Estructura

```
index.html            — sitio completo (single page)
css/style.css         — estilos + responsive (820px / 460px)
js/main.js            — lightbox, embeds YouTube, booking form (Web3Forms)
assets/images/press/  — fotos de prensa
assets/videos/        — clips de prensa
nislo-press-kit.zip   — press kit descargable (código: 0000)
robots.txt / sitemap.xml
```
